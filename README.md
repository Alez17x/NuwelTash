# NuwelTash

NuwelTash es una plataforma inteligente de organización y productividad impulsada por inteligencia artificial.

Su objetivo es comprender los hábitos, prioridades y metas de cada usuario para crear una planificación personalizada, optimizar el tiempo y mejorar el aprendizaje de forma continua.

## Estado del proyecto

En desarrollo.
